# aktujo-tui

The terminal interface of [aktujo](https://aktujo.dev) (ratatui): spaces, documents, search, kinds, sync and sharing,
with the keyboard alone or with the mouse, in the language of the environment (texts from `aktujo-locales`). It works
through the workspace of `aktujo-sdk` only; `aktujo tui` starts it.

AGPL-3.0-or-later. Part of [aktujo](https://github.com/aktujo/aktujo).
